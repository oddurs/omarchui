Omarchy, tuned.

Omarchy gets the hard parts right. Every action is a keystroke away, windows tile themselves, and one theme recolors the whole machine. What it lacks is a shared grammar: each part sizes, spaces and colors itself. This study keeps the paradigm and adds the structure.

    Seven adjustments, no new features

    Each row names how Omarchy draws something today and the change. None of them adds a capability. They make the parts agree with each other.

     TodayTuned
    UnitEach config picks its own sizes and gaps.One 4px unit. Gaps, padding, bar height and row height are all multiples of it.
    FocusA 2px accent border marks the active window.A 1px accent border plus a soft halo. The same ring marks a focused window, field, menu row or theme card.
    TypeOne monospace face at one size, everywhere.Mono for what a machine wrote, a sans for what a person reads. Six sizes, no others.
    ColorThe palette is mapped by hand in each app's config.Eighteen colors with names by job. Every app reads roles, so a theme is one file.
    BarA row of modules with even spacing.Three zones: where you are, when it is, what the machine is doing. Labels sit next to the numbers that need them.
    MenusA list of names.Name, one-line description and shortcut on every row, at one row height everywhere.
    DepthSquare, flat, bordered.Still square and flat. Layers step up in tone: wall, surface, raised. Nothing casts a shadow.

    Eighteen colors, each with a job

    An Omarchy theme is already a palette. The tuning names each color by what it does, so the bar, the launcher, notifications and the lock screen ask for the same name and agree. Pick a theme below and every role on this page changes with it.

    Contrast on this theme

    Computed from the palette you are viewing. Faint text is for line numbers and timestamps, never for something you must read.

    4Type2 faces · 6 sizes

    Two faces, six sizes

    Keep the monospace face for what the machine says. Give human text a sans so menus, notifications and dialogs read as sentences.

    Three speeds, one curve

    Motion confirms what you did and gets out of the way. Nothing bounces, nothing fades text in. The curve is cubic-bezier(.2, .7, .1, 1).
